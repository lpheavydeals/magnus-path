- **Apple Business Connect**: same NAP details.
- **LinkedIn company page**: use the medium description; list all three offices.
- **UK only:** Scoot, Thomson Local, FreeIndex (same London text).
- **India only:** Sulekha, IndiaMART (for manufacturer/exporter leads), with the Chennai text.
